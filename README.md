# 🚀 LeadFlow CRM

A modern **Full-Stack Customer Relationship Management (CRM)** application designed to help businesses efficiently capture, organize, and manage customer leads.

Built using **React, TypeScript, Express.js, Tailwind CSS, and Vite**, LeadFlow provides an intuitive interface for managing leads, tracking sales pipelines, viewing analytics, and improving customer engagement.

---

## 🌟 Features

### 🔐 Authentication
- Secure login system
- Admin & Team Member roles
- Session management

### 📊 Dashboard
- Overview of leads and sales
- Interactive charts and analytics
- Real-time statistics

### 👥 Lead Management
- Create new leads
- View lead details
- Edit existing leads
- Delete leads
- Assign leads to team members

### 📈 Sales Pipeline
- Track lead progress
- Visual pipeline management
- Lead status updates

### 📧 Email Integration
- Email notification panel
- Communication tracking

### 🌐 Public Lead Capture Form
- Collect customer information
- Automatically add leads to CRM

### 🔍 API Explorer
- Test API endpoints
- Developer-friendly interface

### 📱 Responsive Design
- Mobile-friendly layout
- Modern user interface
- Optimized for desktop and tablet

# 🚀 Getting Started

## Prerequisites

Make sure you have installed:

- Node.js (v18 or later)
- npm

---

## Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/leadflow-crm.git
```

### Navigate to the project

```bash
cd leadflow-crm
```

### Install dependencies

```bash
npm install
```

---

# 🔑 Environment Variables

Create a file named

```
.env.local
```

Add the following:

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Get your Gemini API key from:

https://aistudio.google.com/app/apikey

---

# ▶️ Running the Project

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
